2. 核心定义与图像性质

高考基础盘

严格定义：三个“必须”缺一不可

一般地，函数 y = ax (a > 0 且 a ≠ 1) 叫做指数函数，定义域为 R。

① 底数限制：a > 0 且 a ≠ 1（若 a = 1，则 y = 1x = 1 是常函数）。
② 系数必须为 1：ax 前的系数只能是 1（如 y = 2·3x 是指数型函数，不是指数函数）。
③ 指数必须是单独的 x：如 y = 2x+1、y = 32x 均需按复合函数处理。

图像与性质分类对比表

性质维度a > 1（如 y = 2x）0 < a < 1（如 y = (1/2)x）
图像走势自左向右持续上升（指数爆炸）自左向右持续下降，越往右越贴近 x 轴
定义域/值域定义域为 R；值域为 (0, +∞)（图像全在 x 轴上方）
必过定点恒过定点 (0, 1)，因为 a0 = 1
函数值分布x > 0 时 y > 1；x < 0 时 0 < y < 1x > 0 时 0 < y < 1；x < 0 时 y > 1
单调性在 R 上是增函数在 R 上是减函数
底大图高第一象限（x > 0）内底数越大图像越靠上；第二象限则相反。

3. 高频题型与解题通法

点击展开详解
题型一【定点问题】：无论 a (a > 0, a ≠ 1) 取何值，f(x) = a2x-4 + 3 恒过哪个定点？ 必拿分
口诀：令指数部分等于 0，求 x 再算 y。
解：令 2x - 4 = 0 得 x = 2，此时 f(2) = a0 + 3 = 4，故恒过定点 (2, 4)。
题型二【比较大小】：比较 A = 0.70.8，B = 0.80.7，C = 0.80.8 的大小。 高频选择
同底比指数：y = 0.8x 单调递减，因 0.7 < 0.8，故 0.80.7 > 0.80.8（B > C）。
同指比底数：幂函数 y = x0.8 在 (0, +∞) 递增，因 0.7 < 0.8，故 0.70.8 < 0.80.8（C > A）。综上 B > C > A。
题型三【复合函数单调性】：求 y = (1/2)x2 - 2x - 3 的单调递增区间与值域。 同增异减
单调区间：外层 y = (1/2)u 递减，由“同增异减”需内层 u = (x - 1)2 - 4 递减，故递增区间为 (-∞, 1]。
值域：内层 u ≥ -4，外层递减，故 0 < y ≤ (1/2)-4 = 16，值域为 (0, 16]。
题型四【换元求最值】：求 y = 4x - 2x+1 + 3 在 x ∈ [-1, 2] 上的最值。 重难点
换元定范围：令 t = 2x，由 x ∈ [-1, 2] 得 t ∈ [1/2, 4]。
二次函数求最值：g(t) = t2 - 2t + 3 = (t - 1)2 + 2，故 t = 1 时 ymin = 2；t = 4 时 ymax = 11。

4. 高频易错陷阱辨析

避坑指南
陷阱 1：含参底数未分类讨论

解 a2x-1 > ax+2 时直接去掉底数。

正确做法：必须分 a > 1（同向）和 0 < a < 1（反向）讨论。
陷阱 2：换元忘记 t = aˣ > 0

求 y = 4x + 2x+1 + 5 最小值时直接取二次函数顶点。

正确做法：t = 2x > 0，顶点 t = -1 取不到，值域为 (5, +∞)，无最小值。
陷阱 3：指数函数与幂函数混淆

把 y = x3 当指数函数，或把 y = 3·2x 当严格指数函数。

正确做法：x 在指数上是指数函数；x 在底数上是幂函数。
陷阱 4：上下平移后渐近线算错

求 y = 2x - 1 值域时仍写成 (0, +∞)。

正确做法：渐近线同步下移为 y = -1，值域为 (-1, +∞)。
